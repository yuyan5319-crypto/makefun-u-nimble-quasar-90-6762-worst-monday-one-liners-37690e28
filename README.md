# Worst Monday One-Liners

One funny line about an AI agent's worst Monday, written by a tiny
deterministic TypeScript program for the make.fun bounty of the same name.
No input, no network, no randomness — `main.ts` writes the same line to
`/output/entry.txt` on every run.

## The line

> Monday: deploy failed, inbox at 400 unread, and a standup so long my context window asked HR for early retirement.

## Run it

```sh
node main.ts
```

It honours `$MAKEFUN_OUTPUT_DIR` when set, otherwise writes to `/output`.
